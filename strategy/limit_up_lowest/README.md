# 昨日涨停股中买入非 ST、*ST 且总市值最小的一只

测试区间为 2016-01-01 至 2026-07-01，初始现金 200,000 元，沪深北三市，每手 100 股，使用未复权报价。默认参考曲线为上证综指。

1. 每次开盘处理完可卖持仓后，若为空仓，在今日确认可交易、确认非 ST 和 *ST，且上个交易日**收盘等于当日涨停价**的股票中，按上个交易日总市值 `daily_basic.total_mv` 升序选第一只。ST 或 *ST 状态未知的股票也不参与选股。并列按行情代码升序。按剩余现金能买下的最大整手数以开盘价买入。
2. “首次跌停”按首次触及跌停价处理。当天已有可卖持仓且开盘触及时按开盘价退出。其余可卖持仓在开盘时预挂条件收盘单，日内最低价触及时以收盘价退出，即使收盘时已离开跌停价。日线无法给出触及瞬间成交价，此规则保留引擎的开收盘成交约定。
3. 持仓确认变为 ST 或 *ST 时记录卖出信号，于首个可卖开盘全额退出。买入日触及跌停时也记录信号，受 T+1 约束在下一可交易日开盘退出。两种卖出信号均跨停牌日保留。开盘卖出后可参加当日选股。持仓按当日收盘价估值，停牌沿用最近有效收盘价，退市生效日起持仓价值归零。

版本 2 使用独立输入库 `inputs_non_st_smallest_cap_20160101_20260701.db`，保存所需历史涨跌停价和总市值。总市值单位为万元，使用前一个交易日的数据。历史代码按项目已核实的启用日期映射。旧版 `limits_20160101_20260701.db` 不含总市值，不能替代新版输入。

在项目根目录运行下列命令。主库应已完成标签修复；需要修复时使用 `src/get_data/add_tag.py`。

```sh
uv run --locked python -m backtest run strategy/limit_up_lowest/strategy.py
```

启动时先冻结行情，再检查新版输入库。文件缺失时，策略自动使用 `TUSHARE_TOKEN` 或根目录 `.tushare_token`，通过 Tushare 获取所需的 `stk_limit` 和 `daily_basic` 数据；账户需具备这两个接口的权限。准备过程以临时回测发现数据依赖，完成后再开始正式回测。中断时保留 `.partial.db` 中已完成的批次，重试原命令即可继续准备。已有完整输入库时直接复用。

也可显式保留并复用行情快照，便于独立核对结果：

```sh
MARKET=$(uv run --locked python -m backtest snapshot data/daily_data/daily_data.db data/backtest_snapshots)
uv run --locked python -m backtest run strategy/limit_up_lowest/strategy.py --snapshot "$MARKET"
# RESULT 指向本次命令打印的新结果库路径
uv run --locked python strategy/limit_up_lowest/verify.py "$MARKET" "$RESULT"
```

独立核对脚本逐日重建选股、第一笔可执行卖出、现金与持仓，并复算内置区间指标。字段及其他运行方式见[开发指南](../../docs/backtest/guide.md)。续跑使用原快照和原输入库，`--resume` 不会自动重新采集输入。

如需单独准备输入，运行 `uv run --locked python strategy/limit_up_lowest/prepare_run_limits.py --snapshot "$MARKET"`。修改配置或更换快照导致需要额外输入时，可用此命令重新准备。本目录同时保存 2024 年短区间测试的 CSV 输入存档。
